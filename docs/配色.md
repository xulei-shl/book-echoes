# 网站配色方案 (Color Scheme)

## 核心设计理念：黑金美学 (Black & Gold Aesthetics)

网站视觉升级为“黑金”与“同色系层级” (Tone-on-Tone) 的设计语言。
旨在解决原方案中暗红色结构带来的视觉割裂感，通过统一的金色系构建骨架与内容，打造更通透、高级的视觉体验。

### 🎨 核心色板

| 颜色 | 色值 | 角色定义 | 使用场景 |
| :--- | :--- | :--- | :--- |
| **流光金 (Gold)** | `#C9A063` | **核心主色 (结构 & 交互)** | 网格线、边框、按钮、悬停光效、高亮文字、装饰元素 |
| **琥珀金 (Light Gold)** | `#D4A574` | **辅助金色** | 浅色背景下的交互元素、次级高亮 |
| **印泥红 (Dark Red)** | `#8B3A3A` | **品牌点缀 (Brand Accent)** | MagazineCover "最新期"标签、装饰色块、BookCollage空状态文字 (不再用于大面积结构,仅保留为窄小语义) |
| **青瓷灰 (Blue Grey)** | `#7B9DAE` | **信息辅助** | 引用、代码块、次要信息 |
| **墨岩黑 (Dark)** | `#1a1a1a` | **深色背景** | Archive 页面、About 弹窗背景 |
| **宣纸白 (Off White)** | `#F2F0E9` | **浅色背景** | 首页、阅读页背景 |

## 🛠️ 组件配色规范更新记录

### 1. 归档页 (ArchiveContent/ArchiveLayout) - 香槟金质感
*   **网格系统**：由暗红 (`#8B3A3A`) 改为 **金色 (`#C9A063`)**，透明度调整为 8%~12%，营造通透感。
*   **背景水印**：月份大字（如“捌”）由红色改为 **金色**，极低透明度融入背景。
*   **文字标签**：年份、卷号、书籍数量等技术性文字统一为 **金色**。
*   **装饰细节**：角落折线、小方块装饰均统一为 **金色**。
*   **交互反馈**：卡片悬停时的边框高亮与光晕效果均为 **金色**。

### 2. 关于页面 (AboutOverlay) - 黑金奢华感
*   **整体结构**：彻底移除红色边框，采用 **全金色系** 边框与分割线。
*   **排版层级**：
    *   H1 标题：`#D4A574` (琥珀金，稍亮)
    *   H2/H3 标题：`#C9A063` (流光金) / `#B8956A` / `#E8D4B0`
    *   正文：灰白色 (`#D4D4D4`)
    *   强调/引用：青灰色 (`#7B9DAE`)
*   **滚动条**：自定义 **金色** 渐变滚动条。
*   **关闭按钮**：常态金色边框，悬停金色高亮。

### 3. 首页 (HomeHero / HomeNavigation)
*   **首页首图背景**：`#1a1a1a` (墨岩黑) + 装饰线条 `#C9A063`/30%
*   **主文字**：宣纸白 (`#E8E6DC`)
*   **CTA 按钮**：黑底金字，默认 `border-[#C9A063]/40 text-[#C9A063]`，悬停 `bg-[#C9A063] text-[#1a1a1a]`
*   **底部导航链接**：默认为宣纸白，悬停变为琥珀金 (`#D4A574`) + drop-shadow 光晕
