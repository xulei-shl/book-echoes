# Lessons Learned

## MagazineCard 背景卡片设计

### 2026-06-18: 背景卡片应学旧版左侧堆叠方式

**背景**：横/竖版自适应的主封面用 `aspect-ratio` + `w-3/5`/`w-4/5` 动态容器，背景卡片需要保持与主封面比例协调。

**关键经验**：
1. **不要用 `left` 显式定位**背景卡片。旧版用 `translate` 从 `absolute` 默认起始位（左缘）偏移，自然形成左侧堆叠效果。
2. **背景卡片必须加 `bg-[#E8E6DC]`**，提供实色书脊边缘，被主封面遮盖的部分有视觉延续。
3. **`aspect-[2/3]` 比 `aspect-[3/4]` 更协调**，更接近真实书籍比例。
4. **全部堆叠在左缘**（translateX 正值右移、负值左移），三张分别从主封面左侧不同位置露出，形成扑克牌叠放感。
5. **横版主封面 `w-4/5`（80%宽）会完全遮盖背景卡片**，这是可接受的——背景卡片主要服务于竖版（大多数书籍封面）。
6. **不要左右散开**，全部集中左侧露出，视觉更紧凑。
